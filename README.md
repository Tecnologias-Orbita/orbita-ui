# orbita-ui

This is the Orbita company's UX / UI libraries repository.

## Libraries

### orbita-ui-react

This is the main library of the group. The tecnologies used are:

- React v19
- Typescript v6
- TailwindCSS v4

The initial documentation is available [here](https://github.com/Tecnologias-Orbita/orbita-ui/tree/main/orbita-ui-react/README.md).
